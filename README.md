# 🏀 Court Check-In

A simple web app for letting friends know you're at the basketball court.

**Parks:**
- Sierra Bella
- Green River Clubhouse
- Cerritos Courts

## Use it
Open the live site: `https://YOUR-USERNAME.github.io/YOUR-REPO/`

Enter your name, tap **Check in** at a park, and tap again to leave.
Check-ins expire automatically after 3 hours.

## Run locally
Open `index.html` in any browser. No build step or dependencies.

## Notes
Check-ins are stored in your browser (localStorage), so they're only
visible on your own device.
